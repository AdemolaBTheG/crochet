# Crova Project Content

## Product Summary

Crova is a beginner-friendly crochet app focused on helping users learn core stitches, start simple projects, and track progress without losing their place.

For the MVP, the product should center on one core loop:

`learn a stitch -> start a beginner project -> track progress -> finish`

## MVP Goal

Build the smallest version of Crova that helps a first-time crocheter go from zero knowledge to completing a simple project with confidence.

## Core MVP Features

- Beginner onboarding
- Guided lesson path
- Small beginner pattern library
- Interactive project steps
- Row and round tracking
- Saved project progress
- Simple resume flow from the home screen

## Must-Have Screens

### 1. Onboarding

Purpose:
Collect basic user context and point them to the right starting experience.

Should include:
- Skill level
- Goal or intent
- Optional handedness

### 2. Home

Purpose:
Act as the main command center.

Should include:
- Continue learning
- Resume current project
- Recommended next action

### 3. Learn

Purpose:
Provide a clear beginner curriculum.

Should include:
- Ordered lessons
- Short descriptions
- Lesson completion state

### 4. Projects

Purpose:
Give users a place to manage active and completed work.

Should include:
- In-progress projects
- Completed projects
- Resume progress quickly

### 5. Pattern Detail / Project Player

Purpose:
Help users follow instructions while tracking rows, rounds, and repeats.

Should include:
- Step-by-step instructions
- Counter UI
- Saved progress

## MVP Tabs

The app should use 3 tabs:

- `Home`
- `Learn`
- `Projects`

Patterns should stay inside the flow for now and do not need their own tab in the MVP.

## Beginner Lesson Content

The initial lesson path should be short and practical.

Suggested starter lessons:

1. Chain Stitch
2. Single Crochet
3. Double Crochet
4. Magic Ring
5. Rows and Rounds

The lesson sequence should support a user reaching a first real project quickly.

## Starter Project Content

The first batch of projects should be easy, fast, and finishable.

Suggested starter projects:

1. Starter Coaster
2. First Granny Square
3. Mini Bookmark
4. Simple Scrunchie
5. Basic Dishcloth

Each project should include:
- Skill level
- Materials
- Estimated time
- Step list
- Progress state

## Home Screen Content

The home screen should answer three questions:

1. What should I do next?
2. What was I working on?
3. What is the fastest way to keep going?

Recommended home modules:
- Continue beginner lessons
- Resume active project
- MVP priorities or current goal

## Project Tracking Content

The project experience should support:

- Row counting
- Round counting
- Repeat tracking
- Current step visibility
- Progress persistence

This is one of the strongest retention features in the MVP and should be treated as core product value, not a side tool.

## Out of Scope for MVP

Do not prioritize these yet:

- Stitch recognition from photos
- AI pattern generation
- Pattern canvas
- PDF or web conversion
- Stash management
- Knitting support
- Large-scale pattern catalog
- Social or community features

## Current Navigation Direction

The current tab structure in the app is aligned to this MVP:

- `Home`
- `Learn`
- `Projects`

This keeps navigation simple and matches the main user journey.

## Product Positioning

Crova should feel like:

- A beginner crochet teacher
- A project companion
- A progress tracker

It should not try to be an all-in-one crafting platform in the first version.

## Short Product Statement

Crova helps beginners learn crochet step by step, start simple projects, and keep track of every row so they can finish with confidence.
